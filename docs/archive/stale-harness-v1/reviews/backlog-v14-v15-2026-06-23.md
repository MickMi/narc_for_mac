## 已应用的修复
1. **I（Must-Fix）**：`PreferencesView` `windowSnapEnabled` 默认 `false`；`AppDelegate` 启动时仅当该 key 为真才 `WindowSnapService.start()`。→ 吸附变为显式 opt-in。
2. **C（小修）**：`⌘1-9` 的 `ForEach` 动态 range → `enumerated` 身份键，消除 SwiftUI 反模式与刷新隐患。

## 仍存的已知边界（非阻塞，建议后续）
- **I 深层**：即便开启吸附，`addGlobalMonitorForEvents(.leftMouseDragged)` 仍无法区分"拖窗口"与"拖文件/选字"，开启状态下仍可能误吸。本期通过"默认关 + opt-in + 偏好里说明"规避；彻底解决需校验前台窗口 frame 实际位移（留 backlog）。
- **H**：通知引擎是死代码（publish-only）。要么后续接一个只读的"统一事件"面板，要么移除。
