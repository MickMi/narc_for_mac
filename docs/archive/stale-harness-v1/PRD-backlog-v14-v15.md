# PRD: v1.4 + v1.5 Backlog（9 功能补规格）

> 背景：弱模型已越界把这 9 个功能全实现了（无规格）。本 PRD 补出"意图基准"，
> 用于：① 弱模型重跑，或 ② 强模型对照现有代码 audit。每个功能独立小节。
> 不含：diff-drawer（已有独立蓝图）、Developer ID 签名/公证（无 Apple 账号，暂缓）、
> Release CI（基础设施，已确认零账号依赖，保持现状）。

---

## A. 智能复制气泡失焦消失
- 目标：终端失焦 / 切 Tab 时，残留的智能复制气泡自动消失。
- 验收：① 选中出气泡 → 切到别的 Tab / 点别的 App → 气泡消失。② **点气泡本身仍能正常触发复制**（不能因消失逻辑把点击吃掉）。
- 边界：不改 ⌘⇧C / dedent / 复制逻辑；不要用 `resignFirstResponder`（会在 onTap 前移除气泡）。

## B. Tab 字体大小可调
- 目标：用户能调终端字号，所有终端 Tab 实时生效并持久化。
- 验收：① 偏好里有字号设置（如 11–18pt）。② 改了之后**所有已开终端**立即变字号。③ 重启 App 后保持。
- 边界：只改终端正文字号，不影响侧栏/UI 字号。

## C. ⌘1~⌘9 切 Tab
- 目标：⌘1…⌘9 跳到第 1…9 个终端 Tab。
- 验收：① ⌘N 选中第 N 个 Tab（存在才切）。② 不与系统/现有 ⌃⌥ 全局键冲突。③ 焦点正确落到该终端可输入。
- 边界：只在 Dashboard 窗口为 key 时生效；超出 Tab 数量的 ⌘N 无操作。

## D. 拖拽重排 Tab
- 目标：侧栏 Tab 可拖拽改变顺序。
- 验收：① 拖动一个 Tab 到新位置，列表顺序更新。② 重排不影响各 Tab 的终端进程 / claude 状态 / 选中态。③ 顺序在关窗重开后保持（与现有"关窗保留"一致即可，跨 App 重启可不持久）。
- 边界：不要因重排重建终端（PTY 必须存活）。

## E. Scrollback 搜索
- 目标：在当前终端的回滚缓冲里搜索文本并高亮/跳转。
- 验收：① 有搜索入口（如 ⌘F）。② 输入关键字 → 命中高亮，可上/下一个跳转。③ 关闭搜索恢复正常。
- 边界：用 SwiftTerm 内置搜索能力（`SearchService`/`TerminalView` 提供的 API）；不自造缓冲扫描。

## F. diff 列表每文件 +/− 行数徽标
- 目标：「最近文件变更」每行显示该文件的 `+X −Y`。
- 验收：① 每行右侧显示增删行数。② 用**单次** `git diff --numstat HEAD` 映射，不为每个文件单独调 git。③ 取不到（新文件/未跟踪）时优雅降级（显示"新文件"或留空）。
- 边界：不阻塞列表渲染（异步取数）。

## G. 用户偏好持久化（悬浮窗位置）
- 目标：悬浮窗被拖动后的位置，重启 App 后恢复。
- 验收：① 拖动悬浮窗 → 退出 → 重开，位置在上次处。② 位置跨屏/分辨率变化时不飞到屏幕外（越界钳回可见区）。③ 首次启动用默认位置。
- 边界：用 `UserDefaults` 存 frame origin；不引持久化框架。

## H. 通知聚合引擎
- 目标：把 IM badge + Claude 事件统一成一个事件流，供 UI 单点订阅；为后续多源监控打基础。
- 验收：① 存在统一 `NotificationEngine`，IM 与 Claude 源各自 publish，UI 单点订阅。② **不与现有 badge/toast/降噪逻辑双触发**——要么引擎成为唯一数据源（现有 `computedState` 改为读引擎），要么引擎此期仅作旁路、**不接管** badge（二选一，蓝图定）。③ 计数口径与现有一致：badge 只计 IM + 外部 approval + 外部 error（沿用降噪规则）。
- 边界：本期不改"内部/外部分流"与声音分级语义；引擎只做聚合，不改提示策略。
- ⚠️ 现状风险（必须解决）：若引擎与 `FloatingWidgetContainer.computedState` 并存且都驱动 badge，会双算。蓝图必须明确二者关系。

## I. 窗口管理拖拽吸附
- 目标：拖动窗口到屏幕边缘自动吸附到对应布局（Magnet 式）。
- 验收：① 拖窗口到边缘区 → 吸附到半屏/四分之一。② 有冷却避免连续误吸。③ **可在偏好里开关**，默认建议关闭（避免打扰）。
- 边界 / ⚠️ 现状风险（必须解决）：现实现用 `addGlobalMonitorForEvents(.leftMouseDragged)`——**任何**左键拖拽（选文字、拖文件、拖滑块）都会触发吸附前台窗口，非常容易误吸。蓝图必须加约束：只在"确实在拖窗口"时吸附（如校验拖拽源是标题栏/窗口移动），或默认关闭 + 明确告知该限制。
