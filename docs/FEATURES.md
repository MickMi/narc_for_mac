# NARC 功能清单

> 本清单只记录用户体验上能看到、能操作、能感知的功能状态。它不是 bug backlog、不是实现计划，也不记录隐藏逻辑。

## 状态口径

- **成熟**: 用户可稳定发现、理解并完成该功能的主要路径。
- **需调整**: 用户已经能看到或使用，但交互、入口、表达、完整性或稳定性仍需要打磨。
- **缺失**: 从产品目标看应该存在，但当前用户还看不到明确入口或完整闭环。

## v2.0.0 · 2026-08-20 · 个人助手与产品收敛

- 当前新增主线是 Quick Capture、Todo、Notes 与 Assistant Hub；实现已接通，仍需完成真实 App 交互验收后再评估是否进入“成熟”。
- Assistant、Notifications、Windows 以编译期内置模块登记；当前没有第三方插件安装、动态 Swift Bundle 或脚本市场。
- Quick Capture 使用 `⌃⌥Q`，同时保留 `⌃⌥N` 面板、`⌃⌥P` 标记窗口及既有布局快捷键；Workspace 和 `⌃⌥W` 不再对用户开放。
- Dock 与悬浮圆点统一使用大写 `N`；真实 App 已将企微 LaunchServices 的 14 条未读同步到悬浮 Badge，并在重启后保持一致。
- GitHub 源码可通过一条命令在本机准备到 `~/Applications/NARC.app`；不提供预编译安装包，首次指南只说明悬浮 `N` 和 `⌃⌥Q`，完成后可从右键菜单重开。
- 当前版本不包含 AI 自动分类、模型 API、Apple Notes/Reminders、云同步或外部连接器。

## 历史：2026-08-20 曾标记为“成熟”的能力

以下表格保留当时的产品判断，仅供追溯；它不是当前发布状态，若与上方开发预览表冲突，以上方为准。

| 功能 | 用户入口 / 场景 | 用户能做什么 |
|---|---|---|
| 桌面悬浮窗 | 桌面常驻 NARC 圆点 | 查看聚合提醒数量，拖动位置，点击打开快速面板 |
| 快速面板 | 点击悬浮窗或按 `⌃⌥N` | 查看监控对象和已标记窗口；用 Esc 关闭 |
| 快速面板键盘导航 | 快速面板打开后 | 用方向键选择条目，用回车打开，用数字键快速进入前 10 个条目 |
| 监控应用管理 | 偏好设置 → 悬浮窗 | 添加应用、启用/停用监控对象、查看应用名称和 Bundle ID |
| 窗口布局快捷键 | 全局快捷键 / 快速面板 Windows 页 / 偏好设置 → 快捷键 | 把当前窗口移动到左半、右半、上下半屏、居中、全屏或四角 |
| 偏好设置窗口 | 快速面板齿轮 / 悬浮窗右键菜单 | 调整主题、悬浮窗尺寸、监控应用、快捷键说明和通知规则 |
| 通知过滤规则 | 偏好设置 → 通知 | 添加规则，按应用和规则类型设置高亮、普通、静音或隐藏 |
| GitHub 源码一条命令 | README 首屏 | 自动检查环境、在本机准备 App、放到用户 Applications，并在失败时给出下一条行动；无 DMG、PKG、预编译 ZIP 或证书步骤 |
| 初次使用引导 | 首次启动 / 悬浮 `N` 右键“使用指南” | 只学习点击悬浮 `N` 和 `⌃⌥Q`；完成后不重复弹出，可随时重开 |

## 历史：2026-08-20 曾标记为“需调整”的能力

| 功能 | 用户入口 / 场景 | 当前用户视角 |
|---|---|---|
| Quick Capture | `⌃⌥Q` / 快速面板 Inbox / Assistant Hub | 直接保存到 Inbox，不先选类型；草稿跨入口保留，之后显式转 Todo/Note；仍需真实交互验收 |
| Todo | Assistant Hub → Todo | 可以查看待完成/已完成项目并切换完成状态；持久化测试已覆盖，列表交互仍需真实 App 验收 |
| Notes | Assistant Hub → Notes | 可以本地搜索、查看预览并确认删除；持久化测试已覆盖，搜索和删除交互仍需真实 App 验收 |
| Assistant Hub | 悬浮窗右键 / 快速面板星光按钮 | 可以在 Inbox、Todo 与 Notes 之间切换；悬浮窗右键入口与重启往返已通过，新 Inbox 路径仍待真实验收 |
| 悬浮窗右键菜单 | 右键 NARC 圆点 | 真实点击已验证可打开 Assistant 和偏好设置，菜单不再出现 Workspace |
| 应用监控列表 | 快速面板 Monitoring 区 / 偏好设置的悬浮窗页 | 查看应用运行状态和 Dock Badge，点击跳转目标应用；企微多实例去重已在真实 14 条状态和 App 重启往返中验证，14→0→再次产生未读仍待可控条件验收 |
| 统一 N 标记 | 菜单栏与桌面悬浮圆点 | 使用同一大写 `N` 语言；Small/Medium/Large 三档悬浮窗已截图核对，菜单栏数字与未知态待真实验收 |
| 悬浮 N 慢点击 | 点击桌面悬浮圆点 | 不再用 300ms 时间门槛丢弃慢点击；未进入拖动且位移小于 5pt 时打开面板，仍需更多辅助输入设备回归 |
| 标记窗口 | `⌃⌥P` / 快速面板 Pinned 区 | 可以把当前窗口加入快速面板并再次唤回；入口和状态反馈还需要更清楚 |
| 已标记窗口管理 | 快速面板 Pinned 区 | 可以查看、打开、临时/持久切换、移除已标记窗口；需要继续打磨可发现性 |

## 缺失

| 功能 | 用户入口 / 场景 | 缺口描述 |
|---|---|---|
| 快捷键自定义 | 偏好设置 → 快捷键 | 当前只能查看快捷键，不能自定义 |
| 监控对象分类管理 | 偏好设置 → 悬浮窗 | 还不能按工作场景组织监控对象分组或排序 |
| 微信重点会话书签 | Assistant（候选） | 当前尚无入口；安全方案是用户显式维护书签并复用应用级 Badge/窗口找回，预计 5–8 个工程日，需另行确认后实现 |

## v2.0.0 · 2026-08-20 · 微信重点会话边界

| 能力 | 当前结论 | 用户可见表达 |
|---|---|---|
| 微信应用级未读 | 已有，读取 macOS LaunchServices Dock Badge | 显示微信整体未读；查询失败保留最后可信状态，不伪造新零值 |
| 重点会话书签 | 可行但未实现 | 未来可保存名称/备注并打开微信或关联独立窗口 |
| 会话级未读监听 | 当前 No-Go | 微信 4.1.11 未暴露稳定 AX 会话行或 unread；必须显示“状态不可见” |
| OCR 监听 | 不进入默认产品 | 需要屏幕录制、只覆盖可见区域且容易误判 |
| 私有数据库 / 注入 / Hook | 永久禁止 | 不读取私有数据，不把升级即失效的逆向能力包装为功能 |

## v2.0.0 · 2026-08-23 · 一条命令获取边界

- 当前唯一支持的普通用户路径是从 GitHub clone 后由同一条命令完成本地准备和启动。
- DMG、PKG、预编译 App ZIP、GitHub Release 安装包、Developer ID、公证和自动更新均不是当前功能，也不在已规划版本内。
- `.app` Bundle 与自动 ad-hoc 签名属于 macOS 本地构建细节；用户无需准备证书或执行额外签名命令。
- Window tools 可能触发 macOS 辅助功能授权；Assistant、Todo、Notes、Quick Capture 和应用级 Badge 不受此权限阻断。
