# NARC 功能清单

> 本清单只记录用户体验上能看到、能操作、能感知的功能状态。它不是 bug backlog、不是实现计划，也不记录隐藏逻辑。

## 状态口径

- **成熟**: 用户可稳定发现、理解并完成该功能的主要路径。
- **需调整**: 用户已经能看到或使用，但交互、入口、表达、完整性或稳定性仍需要打磨。
- **缺失**: 从产品目标看应该存在，但当前用户还看不到明确入口或完整闭环。

## v2.0.0 · 2026-09-17 · 每日回顾先突出最重要的一件事

本阶段替代旧固定间隔提醒，作为可体验预览，不标记成熟。

| 功能 | 状态 | 用户可见结果 |
|---|---|---|
| 自定义每日时间 | 需调整 | 偏好设置 → 提醒，预置 11:00、14:30，支持添加、修改、删除、总开关与只读预览 |
| 任务安排 | 需调整 | Todo 每行固定“安排”入口，可设置下一件事、优先级与可选截止时间；随手记录不增加必填项 |
| 先重点、后列表 | 需调整 | 回顾卡先显示一项最优先任务，再预览最多三项及其他未完成总数；延期项计入总数但不作为推荐 |
| 直接处理 | 需调整 | 完成这一件、整次回顾延后一小时、查看全部直达 Todo、收起；不抢键盘焦点 |
| 错过不轰炸 | 需调整 | 每个时间点一次，无可处理任务不弹，忙碌或休眠后只短暂补最近一次，超过十分钟不追补 |

排序：手动下一件事 > 高/普通/低 > 同级截止时间早的优先 > 新记录优先。全程本地，不连接 AI。截止时间不单独触发提醒，App 需要运行。

## v2.0.0 · 2026-09-16 · 跨桌面找回窗口与应用

已标记窗口在可见桌面时可尝试带到鼠标所在屏幕；位于其他桌面或原生全屏时，优先在原屏幕显示。无法精确定位时仍尝试打开所属 App，并区分“已定位窗口”“已打开应用”与“应用已激活但窗口未显示”。该能力仍需在不同 App、多屏与系统桌面设置下验收。

## v2.0.0 · 2026-09-14 · Inbox 焦点与主动提醒可体验预览

本阶段把 Inbox 从“功能说明与记录列表的集合”收束为一个当下行动入口，并让悬浮球在不打断当前工作的前提下主动提醒 Todo。当前实现已进入可体验预览，信息层级和提醒强度仍待真实使用确认，不能标记为成熟或正式完成。

| 功能 | 状态 | 用户可见结果 |
|---|---|---|
| 状态驱动的 Inbox 焦点 | 需调整 | 有可处理 Todo 时，“下一件事”位于输入区之前并成为唯一主视觉；没有可处理 Todo 时，输入区自然成为第一动作 |
| 待整理记录折叠 | 需调整 | 历史 Inbox 默认只显示一行数量摘要，用户主动展开后再转换或删除，面板不再常驻堆叠功能说明、记录和重复快捷键提示 |

| 非激活主动提醒卡 | 需调整 | 悬浮球旁一次显示一项 Todo，可“完成”“1 小时后”或“收起”；卡片不激活 NARC、不抢键盘焦点，也不打开主面板 |
| 固定低打扰节流（历史） | 需调整 | 已由 2026-09-17 的用户自定义每日回顾替代，不再运行固定两小时间隔或每日三次限制 |
| 本地边界 | 需调整 | 提醒复用唯一的本地 Todo 状态；不连接 AI、账号或网络，不增加权限，不使用 macOS 系统通知或声音；节流状态不保存 Todo 正文或任务 UUID |

## v2.0.0 · 2026-09-11 · 划词创建 Todo 开发预览

本阶段把“其他 App 中已经存在的文字”纳入显式捕获路径。它不改变 Inbox 的默认心智，也不把 NARC 变成后台内容监听器。

| 功能 | 状态 | 用户可见结果 |
|---|---|---|
| 划词创建 Todo | 需调整 | 在其他 App 主动选中文字后，按默认 `⌃⌥T` 创建一条本地 Todo；按住只触发一次，松开后再次按下才允许创建下一条 |
| 长文确认 | 需调整 | 超过 240 个 Unicode 字符簇，或超过 3 个非空行时先确认；取消不写入，确认使用读取完成后的同一快照，不因后续焦点变化重读；超过 65,536 个 UTF-16 文本单元时明确拒绝并要求缩小选区 |
| 成功反馈与撤销 | 需调整 | 短暂提示不显示选区正文；撤销只按本次创建的精确 UUID 删除，同名 Todo 不受影响，写盘失败不伪装为成功 |
| 划词快捷键设置 | 需调整 | 偏好设置提供固定 `⌃⌥` 的安全字母预设；更换立即尝试生效，冲突或系统注册失败时保留原来实际生效的组合与持久化值 |
| 具体界面兼容性 | 需调整 | TextEdit、Safari/Chrome、VS Code、Preview 与企微必须按具体界面分别记录；当前[兼容矩阵](research/selected-text-todo-compatibility.md)所有真实 App 行仍待验证，不能从一个界面推断整个 App |

快捷键触发时先锁定前台 App 与焦点控件，再立即用公开的标准 Accessibility 选区属性发起一次读取；不持续监听、不读取或改写剪贴板、不模拟 `⌘C`，也不使用 OCR、AI、私有 API 或外部服务。手动创建 Todo 与随手记仍不需要辅助功能权限；划词、窗口排列和窗口标记需要该权限。本功能不改变 source-only 分发边界，不增加 DMG、PKG 或预编译 App。

## v2.0.0 · 2026-08-20 · 个人助手与产品收敛

- 当前新增主线是 Quick Capture、Todo、Notes 与 Assistant Hub；实现已接通，仍需完成真实 App 交互验收后再评估是否进入“成熟”。
- Assistant、Notifications、Windows 以编译期内置模块登记；当前没有第三方插件安装、动态 Swift Bundle 或脚本市场。
- Quick Capture 使用 `⌃⌥Q`，同时保留 `⌃⌥N` 面板及既有布局快捷键；当时由 `⌃⌥P` 承担的标记入口，已由上方 2026-09-15 阶段修订为 `⌃⌥P` 打开召回器、`⌃⌥⇧P` 标记或取消标记。Workspace 和 `⌃⌥W` 不再对用户开放。
- Dock 与悬浮圆点统一使用大写 `N`；真实 App 已将企微 LaunchServices 的 14 条未读同步到悬浮 Badge，并在重启后保持一致。
- GitHub 源码可通过一条命令在本机准备到 `~/Applications/NARC.app`；不提供预编译安装包，首次指南只说明悬浮 `N` 和 `⌃⌥Q`，完成后可从右键菜单重开。
- 当前版本不包含 AI 自动分类、模型 API、Apple Notes/Reminders、云同步或外部连接器。

## v2.0.0 · 2026-08-23 · 一条命令获取边界

- 当前唯一支持的普通用户路径是从 GitHub clone 后由同一条命令完成本地准备和启动。
- DMG、PKG、预编译 App ZIP、GitHub Release 安装包、Developer ID、公证和自动更新均不是当前功能，也不在已规划版本内。
- `.app` Bundle 与本地签名属于 macOS 运行细节；普通安装先继承目标位置已有且可验证的本地 signer，干净新用户才创建 `NARC Local Code Signing Identity v1`，后续只复用由本机指纹标记锁定且与 App 一致的身份；用户无需准备证书或执行额外签名命令。
- 本地私钥不离开当前 Mac，CI 与一次性开发构建才显式使用 ad-hoc；这不引入可下载二进制或发行证书链。
- 划词 Todo 与 Window tools 可能触发 macOS 辅助功能授权；手动使用 Assistant、Todo、Notes、Quick Capture 和应用级 Badge 不受此权限阻断。
