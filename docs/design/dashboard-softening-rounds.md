# Dashboard 软化 — 分回合提示词（喂 Open Design / deepseek-v4-flash）

> 背景：deepseek 单次输出硬上限 ~8192 token（pro/flash 一致，服务端截，OD 改不动）。
> 故拆成多回合，**同一个 OD 会话**里依次发，每回合只做一小块、自包含 HTML。
> 回合 1（token 规范）已完成。用 **flash**（快，同上限，45s/轮）。

---

## 回合 2 — 标签页行 Tab Row 四态

```
继续用你上一回合的 token 规范（r1-rr 圆角、sh1-shS 阴影、s4-s20 间距）。
只做一个东西：左侧"标签页行 Tab Row"的自包含 HTML 视觉稿，四种状态，每种都用真实 CSS 实现（不要只用文字描述）：
1. 默认态
2. hover 态（:hover）
3. 选中态（当前打开的 tab）
4. 需关注态（左侧竖条 + 淡红底）
每行内容：左侧状态圆点 + 标题"Terminal 1" + 下方灰色路径 ~/narc_for_mac + 右侧一个彩色状态徽标占位。
要求：纯 CSS、不引框架不外链；深浅色双模（并排展示两套或加切换）；squircle 连续曲率圆角。
只做 Tab Row 这一个组件，篇幅控制在一次能写完，不要附带其它组件或 token 表。
```

## 回合 3 — Claude 状态徽标（四种）

```
继续用你的 token 规范。只做"Claude 状态徽标"这一组小组件的自包含 HTML，四种，各用真实 CSS：
1. 运行中（蓝色，柔和脉冲动画，非红点）
2. 等待输入（绿色）
3. 需审批（红色，醒目但不刺眼）
4. 已结束（灰色）
每个徽标 = 小圆点/图标 + 一行短文字（思考中 / 等待输入 / 待审批 / 已结束）。
纯 CSS、深浅双模、squircle 圆角。只做这组徽标，篇幅控制在一次写完。
```

## 回合 4 — 工具栏 + 空状态 + 全景外框

```
继续用你的 token 规范。只做这几块的自包含 HTML：
1. 顶部工具栏 toolbar：终端图标 +「NARC Workspace · 3 个终端」+ 右侧「新建终端」胶囊按钮（含 hover）。
2. 空状态：居中大终端图标 +「还没有终端」+「新建终端」按钮。
3. Dashboard 整体外框示意：左列 + 右列 + 分隔；左列放 2-3 个 Tab Row 占位即可（不用重复写四态细节）。
纯 CSS、深浅双模、squircle 圆角。篇幅控制在一次写完。
```
