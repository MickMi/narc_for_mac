# NARC for Mac

**随手记，随时问，及时回到重要的事。**

NARC 是一个常驻 Mac 菜单栏和桌面悬浮球的轻量工具。你不用先切换到另一套工作界面，就能记下一件 Todo、向 AI 提问、搜网页，或找回正在处理的窗口。等 Codex 回复时，也可以先做别的事，让 NARC 提醒你回来。

它默认不占用程序坞。点击菜单栏或桌面上的 **N** 打开面板，也可以用快捷键直达各个功能。

| 你想做什么 | NARC 怎么帮你 |
|---|---|
| 突然想到一件事 | 快捷键呼出输入框，回车就记成 Todo |
| 想问一个问题或看一张截图 | 直接问 DeepSeek，支持连续追问、流式回答和 Markdown |
| 想查最新网页信息 | 内嵌 Bing / Google 搜索，点击结果用系统默认浏览器打开 |
| 等 AI 做完，又不想一直盯着 | 接收 Codex 回复提醒，点击回到对话 |
| 窗口太多，找不到刚才那一个 | 标记窗口，用数字快捷键召回；也能快捷排列窗口 |

**当前是 v2 开发预览，不是稳定发布版。** 本文描述当前源码的能力；安装旧版本时界面可能不同。划词、多屏、全屏桌面及不同应用的窗口兼容性仍需实际体验。

## 安装

需要 macOS 14 或更新版本、Git 和 Xcode Command Line Tools。首次下载和构建需要联网；不需要 Apple 开发者账号，也不需要 `sudo`。

### 1. 准备开发工具

如果尚未安装，在「终端」执行，按系统提示完成安装：

```bash
xcode-select --install
```

已有开发工具可以跳过这一步。

### 2. 下载并安装

在终端粘贴这一行并回车：

```bash
git clone https://github.com/MickMi/narc_for_mac.git && cd narc_for_mac && bash scripts/install.sh
```

脚本会在你的 Mac 上编译、准备本机签名，将应用安装到 `~/Applications/NARC.app`，然后自动启动。完成后可以关闭终端。

如果你已经下载了源码，在项目文件夹中运行 `bash scripts/install.sh` 即可，不用再次克隆。

NARC 目前只提供源码安装，不提供 DMG、PKG 或预编译 App 下载。首次安装会创建本机自签身份，更新时复用；已有可用的 NARC 签名身份会被保留。签名私钥留在本机，不上传或随源码分发。

### 3. 找到 NARC

- 点击菜单栏或桌面悬浮球上的 **N** 打开面板；悬浮球可以拖动。
- 右键点击 **N**，进入偏好设置或使用指南。
- 没看到图标？用 Spotlight 搜索 **NARC**，或在终端运行 `open ~/Applications/NARC.app`。它默认没有 Dock 图标。

## 先用起来

下面的快捷键都是默认值，可在 **设置 → 快捷键** 修改。已有自定义配置不会被新默认值覆盖，以设置里显示的组合和启用状态为准。

`⌃` = Control，`⌥` = Option，`⇧` = Shift，`⌘` = Command。

| 快捷键 | 用途 |
|---|---|
| `⌃⌥Q` | 快速记一件 Todo |
| `⌃⌥⇧D` | 问 AI |
| `⌃⌥B` | Bing 搜索 |
| `⌃⌥G` | Google 搜索 |
| `⌃⌥N` | 将悬浮球和面板呼到鼠标所在屏幕 |
| `⌃⌥T` | 将其他应用中选中的文字记成 Todo |
| `⌃⌥⇧P` | 标记 / 取消当前窗口 |
| `⌃⌥P` | 打开已标记窗口选择器 |
| `⌃⌥1–9` | 直接召回标记列表中的第 1–9 个窗口 |

### 记 Todo：想到就记，不先分类

按 `⌃⌥Q`，输入一件事，按 Return 保存为 Todo。也可以在悬浮面板的 Todo 页直接记录、修改、完成、恢复或删除。

选中其他应用里的文字后，按 `⌃⌥T` 可以创建 Todo。长文本会先要求确认；此功能依赖目标应用提供可读取的选区，扫描图片或部分应用界面可能不支持。

在 **设置 → 提醒** 配置每日提醒时间。提醒需要 NARC 保持运行，不会同步到 Apple 提醒事项。旧版随手箱记录会并入 Todo；已有 Notes 保留，但没有笔记时不显示空的 Notes 页签。

### 问 AI / 搜网页：同一窗口，三个独立入口

按 `⌃⌥⇧D`，或点击悬浮面板顶部的星光按钮，打开 **NARC 搜索**。窗口中可切换「问 DeepSeek」「Bing 搜索」「Google 搜索」，无需进入 Assistant。

**第一次问 AI，先配置密钥：**

1. 打开 **设置 → 即时问答**，填入自己的 DeepSeek API Key，点击「保存」。
2. 如果显示「尚未授权读取」，点击「授权读取密钥」。需要认证时，macOS 会弹出钥匙串提示；授权过程不发送 AI 请求。
3. 显示密钥就绪后可以提问，也可以点击「验证连接」。验证会发送一次真实请求，可能计入你的 DeepSeek 额度。

AI 请求使用你的 DeepSeek 账户，费用由服务方计入该账户。当前源码请求模型为 `deepseek-flash`；文字、图片请求是否可用还取决于服务端和账户支持。

**日常使用：**

- 呼出 AI 后直接输入，按 `⌘Return` 或点击「发送」；回答逐步显示并支持 Markdown，可继续追问。
- 在输入框中用 `⌘V` 粘贴剪贴板图片，或点框内回形针选择图片。缩略图可点击放大，按 Esc 或「完成」返回。
- 图片只用于当前一轮：回答成功后自动移除，失败时保留便于重试。后续文字追问仍有对话上下文，但不会重复发送原图片；要再次分析它，请重新添加。
- 「保存本次对话」保存全部文字回合；「复制本轮回答」只复制最新一条 AI 回答。图片不随对话保存。
- 「清空当前」清除当前问答，不删除已保存记录；关闭搜索窗口也会清除未保存的问答。需要保留时，请先主动保存。

**AI 问答不等于联网搜索。** 当前 NARC 不为 DeepSeek 接入网页检索：要查实时消息、网页或来源，切到 Bing / Google，或直接按 `⌃⌥B` / `⌃⌥G`。搜索页面内嵌显示，结果链接交给系统默认浏览器；「刷新」重新加载当前页。网页搜索不需要搜索 API Key，也不会自动把结果发送给 DeepSeek。

### AI 回复提醒：做别的事，等它提醒你

在 **设置 → AI 回复** 按提示允许并连接。连接需要本机有 Python 3.11 或更新版本，并会调整本机 Codex 通知配置、保留已有通知入口。首次连接后若提示需要重启客户端，请先保存工作，再完全退出并重开。

Codex 任务回复结束时，NARC 在悬浮球旁显示提示。自动弹出的提示约 10 秒后收起，未读回复仍可从悬浮球的蓝色数字或面板「AI 回复」页查看。点击「继续对话」返回对应任务；可关闭某条提示，或在设置里静音某个对话。

这是 **Codex 任务的回复提醒**，不是普通 GPT 聊天的通知，也不是 DeepSeek 问答功能。有回合详情时直接使用原回复中的内容，不额外调用模型生成通知摘要；并非每条回复都有详情。

### 窗口与消息：少找一次，少切一次

先点一下要保留的窗口，按 `⌃⌥⇧P` 标记。之后按 `⌃⌥1–9` 直达，或按 `⌃⌥P` 打开选择器，用数字、方向键 + Return 或鼠标召回；Esc 取消。

数字对应标记列表顺序，可在列表中调整。最多标记 10 个窗口，第 10 个从选择器访问。标记的是具体窗口，不是整个应用；窗口关闭后可能需要重新标记，跨桌面召回受 macOS 和目标应用限制。

窗口排列默认使用 `⌃⌥←/→/↑/↓` 放到左、右、上、下半屏，`⌃⌥U/I/J/K` 放到四角，`⌃⌥Return` 铺满屏幕，`⌃⌥C` 居中。同方向再次触发可尝试移到相邻屏幕；在面板「窗口」页可以启停或修改布局快捷键。

「消息」页还可查看微信、企业微信、飞书等应用暴露给 macOS 的未读徽标。不读取聊天正文，也不能定位是哪条聊天；数字取决于来源应用，未知状态会显示 `?`。

## 权限与数据

- **辅助功能权限**：划词 Todo、窗口标记和排列需要。按引导到 **系统设置 → 隐私与安全性 → 辅助功能** 开启 NARC，再回到目标应用操作。手动 Todo、AI 问答和网页搜索不需要此权限。
- **API Key**：持久保存于 macOS 钥匙串，显式读取后只在当前进程缓存。应用重启后若显示尚未授权，请到设置主动读取；是否弹密码框由 macOS 决定。「始终允许」不是每次更新都免提示的保证，钥匙串或签名身份变化仍可能要求授权。
- **本地记录**：Todo / 既有 Notes 位于 `~/Library/Application Support/NARC/assistant-v1.json`；主动保存的问答位于同目录的 `instant-questions-v1.json`。没有云同步。
- **外部请求**：发送 AI 问题时，问题、最近的文字上下文和本轮图片会发给 DeepSeek；搜索词会发给所选搜索引擎。未保存不代表服务方不留记录，外部数据处理以对应服务政策为准。
- **回复提醒**：在本地处理对话标识、标题、状态，以及原回复中提取的有限回合摘要、下一步和阻塞信息，不保存完整聊天正文。已有通知程序仍可能接收原始事件；关闭或静音提醒只停止展示，不等于断开通知接收。

## 更新与卸载

更新前先保存需要保留的问答，再从 NARC 菜单选择 **Quit NARC**。在原项目文件夹中执行：

```bash
git pull --ff-only && bash scripts/install.sh
```

更新会保留本地记录和现有签名身份。若你改过源码而导致拉取失败，请先处理自己的改动，不要强制覆盖；仅重装当前源码可运行 `bash scripts/install.sh`。

卸载时先退出，再将 `~/Applications/NARC.app` 移到废纸篓。本地记录、API Key 和签名身份不会随应用自动删除；需要彻底清理时先备份记录，再单独处理。

## 遇到问题

**快捷键没反应？** 先确认 NARC 正在运行，再查看「设置 → 快捷键」的启用状态和实际组合。划词与窗口操作还要检查辅助功能权限；与其他软件冲突时换一个组合。

**Key 已保存，AI 仍提示未授权？** 「已保存」不等于「本次运行可读取」。到「设置 → 即时问答」主动授权，再提问；授权成功也不等于 API 连接成功，可单独验证连接。

**安装提示 NARC 正在运行？** 从菜单正常退出后重试。安装器不会强行退出应用或覆盖运行中的程序。

**签名或钥匙串报错？** 保留终端原始错误，先确认登录钥匙串可访问。安装器会在编译前实际签名并验签，失败时不会替换原应用，也不会自动换身份。已解锁仍重复出现 `errSecInternalComponent` 等错误时，不要反复安装或删除证书，重新登录 / 重启后再检查。
