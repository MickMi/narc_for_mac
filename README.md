# NARC for Mac

**Attention Is All You Need. 留给重要的事。**

NARC 是一个面向多任务并行场景的注意力召回助手，将待办事项、AI 回复提醒和常用窗口汇聚在一个桌面悬浮球中。不用反复查看、不必来回寻找，及时回到最需要你关注的事。

常驻 Mac 顶部菜单栏和桌面悬浮球，不占用程序坞。

本文介绍正在迭代的 v2 开发预览版；部分功能尚未合并到默认分支，安装后以实际版本为准。

## 一、安装说明

### 安装

需要 **macOS 14 或更新版本**，以及 Git 和 Xcode Command Line Tools。首次安装需要联网。

打开 Mac 的「终端」，粘贴下面这一行并回车：

```bash
git clone https://github.com/MickMi/narc_for_mac.git && cd narc_for_mac && bash scripts/install.sh
```

等待安装完成，NARC 会自动启动。无需下载 DMG，也不用手动准备证书；安装后可以关闭终端。

如果提示缺少开发工具，先运行下面的命令，按系统提示安装完成后，再执行上面的安装命令：

```bash
xcode-select --install
```

### 安装后怎么用

- 在顶部菜单栏找到 **N**，或点击桌面上的悬浮 **N**，即可打开面板。
- 按 **Control + Option + Q**，输入一件事，回车保存。
- 右键点击 **N**，打开偏好设置或使用指南。
- 以后也可以用 Spotlight 搜索 **NARC** 打开；它默认不出现在程序坞中。

首次使用划词或窗口工具时，按提示到 **系统设置 → 隐私与安全性 → 辅助功能** 开启 NARC，然后回到原窗口再操作一次。手动记录和管理待办不需要这项权限。

### 更新

先从 NARC 菜单选择 **Quit NARC（退出）**，再在最初下载的项目文件夹中打开终端，运行：

```bash
git pull --ff-only && bash scripts/install.sh
```

更新后会自动启动，已有记录会保留。

## 二、功能说明

- **随手记**：想到什么先记下来，回车保存，之后再整理成待办或便签。
- **待办事项**：设置优先级、截止时间和“下一件事”，完成后勾掉，暂时不做就延后。
- **每日提醒**：在「设置 → 提醒」选择每天的提醒时间，先看最重要的一件事，再看其他待办。
- **便签**：保存想法和资料，需要时搜索查找。
- **划词变待办**：选中文字，按 **Control + Option + T** 创建待办；较长内容会先让你确认，部分应用暂不支持。
- **随处呼出悬浮球**：按 **Control + Option + N**，把悬浮球叫到鼠标所在的屏幕。
- **找回常用窗口**：按 **Control + Option + Shift + P** 标记窗口，再按 **Control + Option + P** 打开列表，用数字键快速找回。
- **窗口排列与跨屏移动**：用快捷键把窗口放到半屏、四角或居中；窗口已贴边时，再按同方向快捷键可尝试移到相邻屏幕。
- **未读消息提示**：集中查看微信、企业微信、飞书等应用的未读数量；不读取聊天正文，数字是否可用取决于对应应用。
- **AI 回复提醒**：在「设置 → AI 回复」按提示连接，Codex 任务回复结束后提示你，点击继续对话；也能单独关闭某个对话的提醒。
- **自定义快捷键**：在「设置 → 快捷键」按习惯修改；窗口布局也能在面板的 Windows 页面直接改键或停用。

以上快捷键均为默认设置，以你在应用中保存的组合为准。

提醒需要 NARC 保持运行。AI 回复提醒目前仅支持 Codex 任务，不支持普通 GPT 聊天，连接需要本机具备 Python 3.11 或更新版本；它不是在 NARC 内与 AI 聊天。

随手记、待办和便签保存在本机，无需连接 AI，也没有云同步。
